# موقع مفاجأة عيد ميلاد حبيبتي ❤️🎂

موقع ويب رومانسي متكامل واحترافي مصمم خصيصاً ليكون بمثابة مفاجأة عيد ميلاد رومانسية فاخرة ودافئة لحبيبتك (تاريخ الميلاد: 31/10/2005).

---

## ✨ المميزات الرئيسية للموقع

1. **الهوية البصرية الرومانسية الفاخرة:**
   - لوحة ألوان دافئة وناعمة: الوردي الهادئ، الأبيض الكريمي، البيج اللطيف، درجات الموف الناعمة، ولمسات ذهبية رقيقة.
   - خطوط عربية أصيلة وأنيقة (`Cairo` للعناوين والواجهات و`Amiri` للرسائل العاطفية).
   - قلوب متحركة تسبح بنعومة في الخلفية عبر تقنية Canvas عالية الأداء (60fps).
   - تصميم متجاوب 100% (Responsive) ومتقن تماماً على الموبايل والتابلت والكمبيوتر.

2. **عداد تنازلي ذكي ودقيق:**
   - عبارة ترحيبية رومانسية: *"كل ثانية بتقربني من أجمل يوم.. يوم ميلاد أجمل إنسانة في حياتي ❤️"*.
   - عداد مباشر بالثواني والدقائق والساعات والأيام.
   - موجه بدقة لتوقيت مصر المحلي (`Africa/Cairo`) حتى الساعة 12:00 منتصف الليل مع بداية يوم 31 أكتوبر 2026.

3. **الفتح التلقائي الدائم للمفاجأة (Permanent Auto-Unlock):**
   - بمجرد انتهاء العد التنازلي، تظهر ألعاب نارية من القلوب والألوان الاحتفالية.
   - ينتقل الموقع تلقائياً إلى صفحة المفاجأة الرئيسية.
   - تُسجل حالة الفتح فوراً وبشكل دائم في قاعدة البيانات.
   - لا يظهر العد التنازلي مجدداً نهائياً، وتفتح صفحة المفاجأة مباشرة حتى عند إعادة فتح المتصفح أو الدخول من جهاز آخر.

4. **لوحة تحكم إدارية خاصة ومحمية (Admin Dashboard):**
   - زر وصول أنيق وصغير أعلى الموقع.
   - نافذة تسجيل دخول بكلمة مرور سرية خاصة بك.
   - مصادقة آمنة من طرف الخادم (Server-side Authentication) بترميز JWT وحفظ كلمات المرور مشفرة بواسطة خوارزمية `Bcrypt`.
   - إمكانية تغيير كلمة المرور في أي وقت من داخل لوحة الإدارة.
   - التحكم الكامل في:
     - تعديل عبارات الترحيب والعناوين.
     - تعديل الرسالة الرئيسية ("رسالة من حبيبك ❤️").
     - رفع صور الذكريات الأربعة مباشرة من جهازك مع المعاينة الفورية.
     - تعديل عناوين الصور والملاحظات الرومانسية لكل صورة.
     - إضافة وتعديل وحذف ألقاب وكلمات الدلع ("دلع بنوتي 🥰").
     - ميزة معاينة صفحة المفاجأة فوراً أو إعادة قفل الموقع للعد التنازلي للتجربة.

5. **قسم الرسالة الرئيسية ("رسالة من حبيبك ❤️"):**
   - ورقة رسائل حب فاخرة بتأثير الخط اليدوي والأختام الذهبية.
   - تدعم نصوصاً غير محدودة، فواصل أسطر، وفقرات، وتتمدد تلقائياً بدون شريط تمرير داخلي مزعج.

6. **قسم ذكرياتنا سوا ("ذكرياتنا سوا 📸❤️"):**
   - 4 كروت صور بتأثيرات Hover ناعمة.
   - عند الضغط على أي صورة، تفتح نافذة منبثقة رومانسية تعرض نص "الملاحظة" الذي كتبته لها.

7. **قسم دلع بنوتي ("دلع بنوتي 🥰"):**
   - بطاقة عائمة ومرحة تضم كل ألقاب الدلع المميزة بينكما.

8. **مشغل موسيقى رومانسي اختياري:**
   - زر عائم هادئ في الأسفل يتيح تشغيل وإيقاف لحن رومانسي ناعم (دون تشغيل قسري مزعج).

## 🚀 كيفية تشغيل الموقع محلياً

### 1. تشغيل الخادم
افتح موجه الأوامر (Terminal / PowerShell) في مجلد المشروع، ثم نفذ:

```bash
npm run dev
```

أو لتشغيل النسخة الإنتاجية السريعة:
```bash
npm start
```

### 2. فتح الموقع
افتح المتصفح على الرابط:
`http://localhost:3000`

---

## 🔒 معلومات الدخول للوحة التحكم

- اضغط على زر **لوحة التحكم** الأنيق في أعلى الصفحة.
- أدخل كلمة المرور السرية الخاصة بك التي تعرفها وحدك.
- يمكنك تغيير كلمة المرور في أي وقت من تبويب "كلمة المرور" داخل اللوحة.

## ☁️ خطوات الربط بقاعدة بيانات Supabase (اختياري)

الموقع يعمل محلياً ومستقلاً بنسبة 100% بدون أي إعداد إضافي بفضل قاعدة بيانات SQLite المدمجة وتخزين الملفات المحلي.
إذا رغبت في رفعه على الاستضافة السحابية مع Supabase:

1. أنشئ حساباً ومشروعاً جديداً على [supabase.com](https://supabase.com).
2. افتح **SQL Editor** داخل لوحة Supabase، والصق محتوى الملف المرفق `supabase_schema.sql` واضغط **Run**.
3. احصل على:
   - رابط المشروع: `Project URL`
   - المفتاح السري: `service_role secret key`
4. ضعهما داخل ملف `.env.local`:
```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-secret-key-here
```
وسيقوم الموقع تلقائياً برفع وتخزين الصور على Supabase Storage ومزامنة البيانات سحابياً!
